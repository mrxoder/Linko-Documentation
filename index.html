Overview

Linko is a privacy-first, self-hosted URL shortener built for developers, startups, and businesses who need full control, security, and detailed analytics without relying on third-party services.

  • Create short links with custom or random slugs
  • Protect private links with passwords and expiration dates
  • Track detailed statistics: country, IP address, referrer, operating system, and device type

System & Server Requirements

Before installing Linko, ensure your server meets the following minimum requirements. These requirements are intentionally lightweight to allow easy deployment on shared or VPS hosting.

  • PHP: Version 8.0 or higher
  • PHP Extensions:
    • PDO — required for database abstraction
    • PDO_SQLite — required for SQLite database support
  • Writable Directories:
    • storage/ — used for application data SQLite (currently supported), logs, and cache
  • Note: Additional database engines may be introduced in future updates.

Installation

Follow these steps to install Linko on your server:

  1. Extract the downloaded file to your server and point your domain or subdomain to the public/ directory.
  2. Web server configuration:
    • Apache: Routing to index.php is already handled by the included .htaccess file.
    • Nginx (Advanced Users): To properly route all requests to index.php in the public/ directory, you need to add a configuration like this: 
      location / {
    try_files $uri $uri/ /index.php?$query_string;
}
  3. Visit the URL. The installation page will appear. Check that all requirements are met:
    • PHP >= 8.0
    • PHP Extensions: pdo, pdo_sqlite
    • storage/ directory is writable
  4. Click Next and fill in all required fields:
    • Admin configuration: Admin name, email, new password
    • App settings: App name
  5. If all requirements are fulfilled, the Ready to Install screen will appear. Click Install to complete the installation.

Possible Installation Errors

  • The application is already installed.
    Solution: To reinstall, delete the .env file and any storage/database*.db files. If needed, make a backup of your database before deleting.
  • The provided email address is invalid.
    Solution: Make sure you enter a valid email in the correct format (e.g., user@example.com).
  • Some required installation fields are missing or invalid.
    Solution: Check that all fields are filled correctly and meet the format requirements.
  • Unable to connect to the database.
    Solution: Ensure that the storage/ directory is writable and the database is accessible.

Dashboard Overview

The Linko dashboard provides a central hub for managing links, tracking performance, and accessing key settings.

1. Top Navigation & Global Actions

  • App Name: Positioned in the top-left corner for quick brand identification.
  • Settings: A gear icon in the top-right corner provides access to account and application configurations.
  • Create New Link: A prominent blue "+ New Link" button allows users to initiate the URL shortening process immediately.

2. Analytics Overview (Cards)

Two high-level metric cards give a quick snapshot of your link performance:

  • Total Shortened Links: Displays the total number of URLs created by the user.
  • Total Clicks: Tracks the aggregate number of times all shortened links have been accessed.

3. Link Management Table

The main dashboard section lists all active and inactive links, with detailed data for management:

  • Short URL: Displays the shortened link (e.g., https://.../l/my-product).
    Feature: Includes a copy icon for quick clipboard access. Click the short URL to view detailed statistics for that link.
  • Original URL: Shows the destination address.
  • Expiration: Indicates when the link will cease to function (e.g., "No Expiration").
  • Clicks: Displays the click count for that specific link, accompanied by a small trend icon. Click the number to open detailed statistics.
  • Actions: Tools to manage individual links:
    • Edit (Pencil Icon): Modify the destination URL or short link alias.
    • Delete (Trash Icon): Permanently remove the link.
    • Toggle Switch: A green switch indicates the link is Active. Use it to temporarily disable the redirect without deleting the link.

Create a Short Link

Use the + New Link button on the dashboard to open the modal for creating a new shortened URL.

Core URL Information

  • Original URL: A required field where you enter the long destination address (e.g., https://very.long.url/...).
  • Custom Slug (Optional): Allows you to define a personalized ending for your link. Enter a custom name (e.g., my-product) to make the link more recognizable.

Advanced Settings

  • Expiration Date (Optional): Set a specific date for the link to expire.
    Behavior: The link becomes inaccessible starting at 00:00 on the chosen date.
    Interface: Includes a calendar icon for selecting the date.
  • Private Link (Optional): Protect the link with a password.
    • Password: Enter a security code.
    • Confirm Password: Re-enter the password to prevent typos.

Actions

  • Cancel: Closes the modal without saving any changes.
  • Shorten URL: The primary blue button that finalizes the creation of the link and adds it to your dashboard.

Visitor Analytics

The Visitor Analytics section provides a comprehensive overview of link traffic and visitor behavior, allowing you to monitor engagement, identify trends, and optimize your links.

Analytics Summary

At a glance, the dashboard presents key metrics through four summary cards:

  • Countries: Shows visit counts grouped by country codes (e.g., FR, PL).
  • Devices: Displays the proportion of visitors using "Desktop" vs "Mobile".
  • Operating Systems: Tracks sessions across different OS platforms (e.g., Android, Linux).
  • Unique IP Visitors: Total count of distinct visitor IPs to your links.

Filters and Search

To analyze specific segments of your traffic, use the available filters and search options:

  • Global Search: Search visitor activity by IP, User-agent, or other available fields.
  • Search Mode Toggle: Select criteria for searching, such as "Search by IP address" or "Search by Device".
  • Category Filters: Narrow results by Proxy usage, Operating System, Device Type, and Country.
  • Date Range: Choose a start and end date using a calendar picker to analyze traffic within a specific period.

Detailed Activity Log

The activity log provides granular information for each visit, helping you understand visitor behavior and technical context:

  • Identifier: Visitor’s IP address for tracking unique sessions.
  • Attributes: Color-coded tags for quick identification of Timestamp, Country, Device, and Operating System.
  • Technical Data: Full User-agent string showing browser and platform details for each session.

SMTP Configuration

SMTP settings allow Linko to send emails for account recovery, notifications, and other automated messages. This configuration is required if you want to enable the Forgot Password feature.

Required Fields

  • SMTP Server: The hostname of your mail server (e.g., smtp.gmail.com for Gmail).
  • Port: The port number used by the SMTP server (commonly 465 for SSL or 587 for TLS).
  • Username: Your email address used to send messages.
  • Password: The password for your email account or app-specific password if required by your provider.

Gmail Configuration Guide

If you are using Gmail, follow these steps to enable SMTP for Linko:

  1. Enable 2-Step Verification: Go to your Google Account → Security → 2-Step Verification, and turn it on.
  2. Create an App Password: In your Google Account, go to Security → App Passwords → Generate a new password for Application.
  3. SMTP Server: Use smtp.gmail.com.
  4. Port: Use 465 for SSL or 587 for TLS.
  5. Username: Your full Gmail address.
  6. Password: The app password generated in step 2.

Tips

  • Make sure your hosting provider allows outgoing SMTP connections on the port you selected.
  • Test your SMTP configuration before enabling the Forgot Password feature:
    Click the "Test Send Mail" button and check your inbox.
    If the test is successful, click the "Save" button to store the configuration.
    Note that running the test will not save the settings automatically.

Security Settings

The Security section allows administrators and users to manage access controls, authentication settings, and activity logging. Proper configuration helps protect your account and the application from unauthorized access.

Admin Controls

  • Enable/Disable New User Registration: Control whether new users can register on the platform.
  • User Management: View a list of registered users, and enable or disable accounts as needed.
  • Enable/Disable Forgot Password Feature: Toggle the ability for users to recover their passwords via email.
  • Web Request Logging: Enable or disable logging of all web requests for monitoring and auditing purposes.
  • Login Rate Limiting: Enable or disable rate limiting for login attempts.
    Default behavior: Enable, after some failed login attempts within defined time, the user’s IP is temporarily blocked to prevent brute-force attacks.

User Controls

  • Connected Devices: View all devices currently logged into your account.
  • Logout Devices: Remotely log out any session or device for account security.
